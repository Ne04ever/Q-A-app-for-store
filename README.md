# 🧠 AtliQ T-Shirts: Database Q&A with LangChain & Streamlit 👕
This project allows users to ask natural language questions about an inventory database of t-shirts, and get answers generated by an LLM that translates those questions into SQL queries and interprets the results.

Built using:
* 🦜 LangChain for LLM chaining
* 🤗 HuggingFace for semantic embeddings
* 🐘 MySQL for the backend database
* 🧠 Cohere LLM
* 🧾 FAISS for semantic similarity search
* 🌐 Streamlit for the user interface

## 🚀 Features
* Ask natural language questions like “How many white Levi’s shirts do I have?”
* Converts them into optimized MySQL queries
* Uses few-shot prompting for better SQL generation
* Uses semantic similarity to pick the best few-shot examples dynamically
* Connects to a MySQL database and fetches live answers
* All wrapped in an easy-to-use Streamlit web app
